# Third-party assets

This repository does **not** distribute any third-party 3D model, texture or
skybox. `front/public/game/models/`, `front/public/game/textures/`,
`front/public/game/skybox/` and `front/public/game/material/` are ignored by Git
and must be populated locally (see below). Screenshots, GIFs and the trailer
were recorded with those assets present and are kept for demonstration only.

## Where to put the files

- **Models** — one folder per model under `front/public/game/models/<folder>/`
  containing `scene.gltf`, `scene.bin` and `textures/`. The folder name is the
  model id returned by `GET /api/models`, and the runtime only loads
  `<folder>/scene.gltf`, so keep that exact filename. Keep the `license.txt`
  generated by Sketchfab next to it.
- **Textures** — `front/public/game/textures/`.
- **Skybox** — `front/public/game/skybox/<name>/` with `front.png`, `back.png`,
  `left.png`, `right.png`, `top.png`, `bottom.png`.

Sketchfab's glTF download already has the right layout: unzip it into the target
folder.

## Before making the repository public

The assets were committed earlier in history. Removing them from the current
tree is not enough — they remain reachable through `git log`. Rewrite history
before publishing:

```bash
git filter-repo \
  --path front/public/game/models \
  --path front/public/game/textures \
  --path front/public/game/skybox \
  --path front/public/game/material \
  --invert-paths
```

Then force-push. If the repository was ever public, assume the files are already
mirrored and treat them as published.
